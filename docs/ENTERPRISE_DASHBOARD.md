# 자동차 품질 조기대응 화면

`자동차품질_화면실행.cmd`를 더블클릭하면 브라우저에서 로컬 화면이 열립니다. 검은 실행창은 서버이므로 화면을 사용하는 동안 닫지 않습니다.

화면에서 LOT 번호, VIN, 협력사, 부품번호, 위험등급으로 검색할 수 있습니다. 결과에는 위험점수, 출고상태, 권고 대응, 예상 순이익과 직접 ROI가 표시됩니다.

상단의 `운영 판단 사용 금지` 경고는 오류가 아니라 실제 의사결정에 필요한 표본 기준이 충족되지 않았다는 뜻입니다. 기업 데이터가 충분히 들어와 기준을 통과해야 상태가 변경됩니다.

서버는 외부 네트워크에 공개하지 않고 이 PC의 `127.0.0.1:8765`에서만 실행됩니다.
