# AutoQ-Guard 현업 검토 안내

## 1. 검토 목적

AutoQ-Guard는 부품 LOT, 공정검사, 차량 VIN, 보증수리, 비용 데이터를 연결해 위험 LOT와 영향 차량을 조기에 좁히는 개인 PoC입니다. 이 문서는 결과를 홍보하기보다, 실제 자동차 품질·생산 현장에서 사용할 가치와 부족한 점을 검토받기 위한 안내서입니다.

## 3. 현재 확인된 것

- 공개자료 176,082행의 형식·필수값·중복·출처 해시 검사
- LOT–검사–VIN–보증수리–비용 데이터 구조와 참조관계 검사
- 규칙 기반 위험 LOT 분류, 영향 VIN 조회, 손익 계산 흐름
- CSV 사전검사, 격리 저장, 후보 DB 생성, 운영 DB 비교
- 표본 기준 미달 시 운영 반영 차단과 기존 DB 보존
- 관리자·품질담당자·조회자 권한 분리와 감사기록
- Python 자동검사 92개 통과, PostgreSQL 대량·동시조회 시험 통과

## 4. 아직 입증하지 못한 것

- 기업의 실제 생산자료에서의 결함 탐지율과 오경보율
- 실제 리콜 예방 차량 수와 리콜 범위 축소율
- 기업 원가·정비·물류·고객보상 기준의 확정 ROI
- 실제 회사 시스템의 MES·QMS·ERP·보증 시스템 연동
- 기업 보안환경의 SSO·KMS·망분리·보안관제 적합성

공개자료에는 사내 부품 LOT와 차량 VIN 연결키가 없습니다. 따라서 공개자료와 기업자료를 임의로 행 단위 결합하지 않았으며, 공개자료는 외부 위험 신호 검증에만 사용합니다.

## 6. 한 문장 설명

> 생산공정 이상과 부품 LOT를 차량 VIN까지 추적해 품질 위험의 대응 우선순위와 예상 손익을 보여주되, 근거가 부족하면 운영 반영을 차단하는 자동차 품질 조기대응 PoC입니다.
