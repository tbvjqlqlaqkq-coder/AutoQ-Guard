# WATCH LOT 검사 우선순위

## 목적

2차 증거가 경보 기준에 미달해도 안전 관련 LOT를 정상으로 폐기하지 않는다. 제한된 검사 인력으로 반복 이상·조기수리·고장코드 집중·협력사 반복 신호가 큰 LOT부터 검토한다.

## 운영 원칙

- 결함 정답은 사후 성능평가에만 사용하고 순위 계산에서 제외한다.
- 순위는 자동 리콜 결정이 아니라 사람 검토 순서다.
- 하루 검사 가능량을 입력하면 예상 검토일을 계산한다.
- 동점은 LOT 번호로 고정 정렬해 결과를 재현할 수 있게 한다.
- 미검토 WATCH는 정상 처리하거나 삭제하지 않는다.

합성시험 결과와 실제 기업 검사능력은 다르므로 운영 전 실제 처리시간·인원·교대조 기준으로 용량을 다시 설정해야 한다.

## 합성 실행 결과

- WATCH 대기 LOT: 12개
- 실제 결함 정답: 1개
- 하루 검사 가능량 가정: 3개
- 실제 결함 LOT 검토순위: 1위
- 첫날 결함 발견: 1개
- 전체 큐 처리 예상: 4일

합성 신호는 우선순위 기능을 시험하기 위해 정답을 참고해 구성했으므로 이 결과를 실제 탐지율로 주장할 수 없다. 기업 실증에서는 정답을 보지 않은 과거 시점의 신호로 순위를 만든 뒤 이후 확정된 결함과 비교해야 한다.
