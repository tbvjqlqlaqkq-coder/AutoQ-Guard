# AutoQ-Guard 기업 파일럿 실증 계획

## 목적

기업 내부 데이터가 들어왔을 때 AutoQ-Guard가 실제 업무에서 위험 LOT의 조사 우선순위를 높이고, 영향 VIN 범위를 좁히며, 조기대응의 경제성을 측정할 수 있는지 검증한다. 파일럿은 자동 출고중지나 자동 리콜 결정을 내리지 않으며 품질 담당자의 의사결정을 보조한다.

## 현재 기준과 기업 실증 기준의 구분

코드에 설정된 `10 LOT·100 VIN 연결·10건 보증수리` 기준은 파이프라인 차단 기능을 확인하기 위한 **기술 데모 최소값**이다. 기업 성능이나 ROI를 확정하는 표본 기준이 아니다.

기업 파일럿의 제안 시작범위는 아래와 같다. 업종·부품·발생률에 따라 통계 담당자와 품질 책임자가 최종 승인해야 한다.

| 항목 | 제안 시작범위 | 이유 |
|---|---:|---|
| 관찰기간 | 과거 12개월 이상 | 계절·설비·협력사 변화 포함 |
| 대상 | 한 공장, 한 부품계통 | 원인과 대응 범위 통제 |
| 부품 LOT | 1,000개 이상 | 정상·이상 LOT 비교 |
| LOT–VIN 장착연결 | 10,000건 이상 | 영향차량 추적과 분모 확보 |
| 보증수리·현장품질 | 300건 이상 권장 | 드문 결함의 평가 불확실성 축소 |
| 시간 분할 | 과거 학습/기준설정 후 미래 구간 평가 | 미래정보 누출 방지 |

수량을 충족해도 결함 양성사례가 지나치게 적으면 성능을 확정하지 않는다. 이 경우 기간 또는 대상 부품을 확대한다.

## 필요한 입력자료

상세 필드는 [`enterprise_data/ENTERPRISE_DATA_REQUEST.csv`](../enterprise_data/ENTERPRISE_DATA_REQUEST.csv)에 정리한다.

1. 부품 LOT와 협력사·부품번호·입고시각
2. 공정검사 결과와 측정값·재검률·검사시각
3. 차량 VIN 대체키와 장착 LOT·생산시각
4. 보증수리·DTC·고장부품·수리비·발생시각
5. 부품·공임·물류·검사·재고·고객보상 비용
6. 품질 담당자가 승인한 모델·연식·부품번호→공개 부품계통 매핑

## 개인정보·영업비밀 보호

- 이름·전화번호·주소·차량 소유자 정보는 받지 않는다.
- VIN 원문이 불필요하면 기업 내부에서 HMAC 처리한 `vehicle_key`만 제공한다.
- 협력사명·부품번호는 기업 내부 코드로 치환할 수 있다.
- 원본은 읽기 전용으로 보존하고 파일 해시·행 수·반입시각·승인자를 기록한다.
- 분석계와 운영계를 분리하고 최소권한, 감사기록, 보유기간, 삭제 절차를 기업 보안정책으로 승인받는다.
- 공개 저장소와 공개 데모에는 기업 원본·매핑키·비용 원장을 올리지 않는다.

## 실행 순서

1. 품질·생산·IT·보안 담당자가 목적과 대상 부품을 승인한다.
2. 데이터 요청표를 기준으로 비식별 표본을 전달한다.
3. 원본 해시와 행 수를 고정하고 표준 열 매핑을 검토한다.
4. 누락·중복·형식·참조관계 검사를 통과한 자료만 격리 적재한다.
5. 과거 구간에서 경보 기준을 고정한다.
6. 이후 시간 구간에서 탐지율·정밀도·선행기간·오경보 비용을 평가한다.
7. 현재 방식과 AutoQ-Guard 보조 방식의 영향 VIN·검사비·예상손실을 비교한다.
8. 품질 책임자가 결과를 검토해 확대, 수정 또는 중단을 결정한다.

## 평가 지표

| 구분 | 핵심 지표 |
|---|---|
| 탐지 | 재현율, 정밀도, F1, PR-AUC, 결함별 신뢰구간 |
| 시점 | 최초 경보부터 품질사건까지의 선행기간 |
| 범위 | 기존 조사 차량 대비 추적 대상 VIN 감소율 |
| 현장 | 오경보 LOT 수, 추가검사 시간, 출고보류 시간 |
| 경제성 | 회피손실, 조기조치비, 순편익, ROI와 민감도 범위 |
| 운영 | 처리 실패율, 소요시간, 감사기록 누락, 복구 성공 여부 |

## Go/No-Go 원칙

정확한 수치는 파일럿 시작 전에 기업 담당자가 승인한다. 다음 원칙은 변경하지 않는다.

- 안전부품은 경제성보다 안전 검토를 우선한다.
- 단일 정확도 수치가 아니라 정밀도·재현율·오경보 비용을 함께 본다.
- 기존 방식보다 성능 또는 업무 효율이 개선되지 않으면 확대하지 않는다.
- 순편익이 0 이하이거나 승인 ROI 기준보다 낮으면 운영 도입을 보류한다.
- 데이터 누출, 참조관계 오류, 미래정보 누출이 확인되면 결과를 폐기하고 재실행한다.
- 운영 반영은 후보 DB 비교와 품질 책임자·관리자의 명시적 승인 후에만 허용한다.

## 파일럿 종료 산출물

- 데이터 품질 보고서와 오류 목록
- 시간순 성능평가 및 오경보 분석
- 위험 LOT와 영향 VIN 비교표
- 비용 가정·민감도·ROI 보고서
- 보안·접근·감사기록 점검표
- 확대/수정/중단 결정서

## 기업 설명 문장

> 기술 데모에서 데이터 반입·검증·위험분석·후보 DB·안전 차단 흐름을 확인했습니다. 기업 파일럿에서는 한 공장과 한 부품계통의 과거 12개월 자료부터 시작해 실제 탐지 성능, 오경보 비용, 영향 VIN 축소폭과 ROI를 시간순으로 측정하며, 기준 미달 시 운영 반영 없이 중단합니다.
