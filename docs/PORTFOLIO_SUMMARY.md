# 포트폴리오 요약

## 한 줄 소개

공개 자동차 불만·리콜 데이터와 합성 생산 LOT를 연결하여 리콜 전 품질위험 탐지 가능성과 예상 회피손실·ROI를 검증한 재현 가능한 개인 PoC

## 문제

자동차 리콜 대응은 결함 확정 후 대상 차량과 수리방법을 정하는 데 강하지만, 공정 이상이 현장 결함과 리콜로 이어지기 전의 판단 구간은 외부에서 확인하기 어렵다.

## 해결 접근

- NHTSA 공개 불만·리콜·조사 데이터 시간순 백테스트
- 경보규칙 사전 고정
- 합성 LOT로 공정–LOT–차량–현장품질 결합 기능시험
- 예상 회피손실·조기조치비·오탐비·고정비·성과금 통합
- 공개·합성·가정·기업 실증의 근거 등급 분리

## 결과

- 공개데이터 12개월 탐지율 20.6%
- 경보 정밀도 8.1%
- 중앙 선행기간 4.5개월
- 합성 LOT 블라인드 기능시험 Gate 통과
- 가정 기반 기준 ROI 34.0%
- ROI 10% 이상 확률 93.6%

## 사용 기술

- Python 표준 라이브러리
- CSV·JSON 기반 데이터 파이프라인
- 시간 순서 백테스트
- 혼동행렬·탐지율·정밀도 평가
- 몬테카를로 경제성 시뮬레이션
- SHA-256 입력 무결성 기록
- Windows 원클릭 실행 스크립트

## 담당 범위

- 문제 정의
- 공개데이터 분석 설계
- 경보규칙 및 검증 Gate 설계
- 합성 생산 LOT 구조 설계
- 경제성·계약 구조 설계
- 재현 가능한 실행 패키지와 결과 등급 체계 구축

## 정확한 완성도 표현

개인 프로젝트형 PoC와 공개데이터 재현성 검증은 완료했다. 실제 기업 생산라인 성능과 ROI는 내부 공정·LOT·차량·보증수리·원가 데이터로 추가 검증해야 한다.
