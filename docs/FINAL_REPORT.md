# 최종 프로젝트 보고서

## 1. 프로젝트 정의

본 프로젝트는 자동차 생산공정·협력사 부품 LOT·차량 장착·현장 품질·리콜 데이터를 하나의 분석 흐름으로 연결하여, 부품 결함이 리콜로 확정되기 전에 위험 신호를 탐지하고 예상 손익을 계산하는 개인 PoC이다.

실제 기업의 생산공정·LOT·VIN·보증수리 데이터는 공개되지 않으므로 다음 세 층으로 검증했다.

1. 실제 공개데이터로 리콜 전 선행 신호 가능성 검증
2. 합성 LOT 데이터로 공정–LOT–차량 분석 흐름 기능시험
3. 명시적 가정으로 회피손실·순편익·ROI 시뮬레이션

## 2. 기존 대응과의 차이

| 기존 리콜 대응 | 본 프로젝트 |
|---|---|
| 결함 확인 후 대상 차량 선정 | 결함 확정 전 위험을 추정 |
| LOT·VIN으로 리콜 범위 결정 | 공정 이상으로 위험 LOT를 조기 탐지 |
| 이미 발생한 리콜 처리 중심 | 출고 전 차단과 사전 대응 검토 |
| 대상 차량·수리방법 결정 | 예상 손실·ROI·재고·고객대응까지 연결 |
| 기업 내부 데이터 기반 | 공개·합성 데이터로 구조와 효과를 사전 검증 |

기존 시스템을 대체하는 것이 아니라 결함 확정 이전의 의사결정 구간을 보완하는 것이 목적이다.

## 3. 데이터와 방법

### 3.1 공개 관측 데이터

- NHTSA 기반 불만 50,441건
- 리콜 레코드 738건
- 조사 레코드 23건
- 분석 기간 2020-01~2026-06

불만 증가, 중대 신호, 조사 신호를 3개월 단위로 결합해 경보를 생성하고, 이후 12개월 안에 같은 브랜드·모델·연식·부품계통에서 리콜이 발생했는지 비교했다.

### 3.2 합성 LOT

공개되지 않는 생산공정 구조를 모사하기 위해 120개 합성 LOT를 사용했다. 생산일 순서로 70%를 기준구간, 30%를 블라인드 구간으로 나눴다. 실제 결함 라벨은 경보 계산 이후에만 평가에 사용했다.

### 3.3 경제성

예방 차량 수, 출고 후 차량당 비용, 조기조치 비용, 고정비, 오탐 비용과 성과금을 결합했다. 20,000회 몬테카를로 시뮬레이션을 고정 시드 `20260730`으로 실행했다.

## 4. 결과

### 4.1 실제 공개데이터

- 12개월 내 리콜 탐지율: 20.6%
- 경보 정밀도: 8.1%
- 중앙 선행기간: 4.5개월
- 경보 에피소드: 2,125건
- 탐지 리콜 레코드: 152건

해석: 공개데이터만으로도 일부 리콜보다 앞선 신호가 존재한다. 반면 정밀도 8.1%는 자동 출고보류에 사용하기에는 낮으므로, 기업 내부 공정·LOT 데이터로 경보 범위를 좁혀야 한다.

### 4.2 합성 LOT 기능시험

- 전체 120 LOT
- 기준구간 84 LOT
- 블라인드 구간 36 LOT
- 고정 경보규칙 Gate 통과

해석: LOT 단위 분석 흐름과 고정 규칙 평가 기능이 작동한다. 실제 기업 성능을 의미하지는 않는다.

### 4.3 경제성 시뮬레이션

- 기준 순편익: 2,956만원
- 기준 ROI: 34.0%
- P10 순편익: 약 1,101만원
- 순편익 양수 확률: 99.3%
- ROI 10% 이상 확률: 93.6%

해석: 설정한 규모와 비용 분포에서는 단계 지급형 설계가 경제성을 보였다. 이 결과는 합성 규모와 가정에 의존하며 기업 ROI 확정값이 아니다.

## 5. 안전·운영 원칙

- 모델은 경보와 검토 우선순위를 제시한다.
- 자동 출고보류·자동 리콜 결정은 하지 않는다.
- 차량키는 가명 처리한다.
- 안전부품은 낮은 확률이라도 보수적으로 검토한다.
- 모든 경보·검토·결정은 감사 가능하도록 기록한다.
- 성능·보안·경제성 기준 미달 시 중단한다.

## 6. 기업 적용 Gate

1. G1: 대상 부품·라인·KPI·중단 기준 합의
2. G2: LOT–차량–현장 데이터 연결 품질 검증
3. G3: 시간 순서 기반 블라인드 백테스트
4. G4: 실제 회피손실·순편익·ROI 검증
5. G5: 보안·법무·품질·운영 승인

G4 목표는 순편익 양수와 ROI 10% 이상이다. 미달하면 확대하지 않는다.

## 7. 결론

본 프로젝트는 공개데이터에서 리콜 전 선행 신호 가능성을 확인하고, 합성 LOT로 분석 흐름을 구현했으며, 경제성 판단 구조까지 재현 가능하게 통합했다.

따라서 개인 프로젝트형 PoC로는 완성되었다. 다만 기업별 실제 탐지율·예방 차량 수·회피손실·ROI는 해당 기업의 내부 데이터가 제공되기 전에는 확정할 수 없다.

기업에는 다음과 같이 제시할 수 있다.

> 외부에서 가능한 사전 검증과 실행 구조는 완성했습니다. 기업의 공정·LOT·차량·보증수리 데이터를 적용하면 해당 기업 기준의 실제 탐지 성능, 영향 차량 수, 직접 회피손실과 ROI를 측정할 수 있으며, 기준 미달 시 조기에 중단할 수 있습니다.
