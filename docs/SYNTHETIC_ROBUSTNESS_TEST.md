# 합성 잡음·경계조건 강건성 시험

## 왜 이 시험을 했나

명확한 이상만 주입한 첫 합성시험은 정밀도와 재현율이 100%였다. 이는 기능 확인에는 유용하지만 현장에서 발생하는 약한 결함 신호와 결함이 아닌 일시적 공정 이상을 반영하지 못한다. 따라서 정답과 경보규칙을 일부러 불일치시킨 더 어려운 시나리오를 추가했다.

## 시나리오

| 유형 | LOT 수 | 정답 | 입력 신호 | 기대되는 어려움 |
|---|---:|---|---|---|
| 명확한 결함 | 20 | 결함 | 강한 공정편차·재검률 | 탐지 가능 |
| 약한 잠재결함 | 10 | 결함 | 임계값 미만 공정신호 | 미탐 가능 |
| 비결함 공정 이상 | 10 | 정상 | 강한 일시적 공정 신호 | 오탐 가능 |
| 일반 정상 | 960 | 정상 | 정상 범위 | 정상 분류 |

## 고정 경보규칙 결과

| 지표 | 결과 |
|---|---:|
| TP / FP / FN / TN | 20 / 10 / 10 / 960 |
| 정밀도 | 66.7% |
| 재현율 | 66.7% |
| F1 | 66.7% |
| 특이도 | 99.0% |

이 결과는 실제 기업 성능 추정치가 아니다. 합성 정답을 독립적으로 바꾸었을 때 평가기가 오탐과 미탐을 숨기지 않고 계산하며, 고정 규칙의 한계를 화면과 보고서에 표시할 수 있다는 기능 증거다.

## 해석

- 약한 결함 신호는 현재 HIGH 기준 아래에 남을 수 있다.
- 공정 이상이 항상 실제 부품 결함을 의미하지 않으므로 강한 수치만으로 출고중지나 리콜을 자동 결정하면 안 된다.
- WATCH 단계의 추가검사, 보증수리 신호 결합, 품질담당자 승인이 필요하다.
- 기업 실증에서는 시간순으로 분리한 실제 결함 라벨을 사용해 같은 지표를 다시 계산해야 한다.

## 재현 명령

```powershell
python src/run_synthetic_robustness.py
```

최종 판단은 **규칙 기반 PoC의 평가·안전 흐름은 작동하지만, 실제 운영 임계값은 기업 실증 전 확정할 수 없음**이다.
