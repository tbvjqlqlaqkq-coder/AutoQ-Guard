# 대량 합성데이터 성능시험

기업형 데이터 구조를 가정해 2,000개 LOT, 20,000대 VIN, 4,000개 공정검사와 합성 보증수리 데이터를 생성합니다. 전체 통합 파이프라인 실행 후 데이터 건수 보존, 데이터베이스 무결성, 판단 기준 통과 여부, 500회 LOT 검색 정확도와 처리시간을 검사합니다.

실행: `대량데이터_성능시험.cmd`

결과: `results/enterprise_stress_test/stress_test_result.json`

이 시험은 데이터 처리 구조와 단일 PC 검색 성능을 검증합니다. 실제 결함 예측 정확도, 기업 서버 동시접속, 정보보안, 운영시스템 연동 성능을 증명하지는 않습니다.
