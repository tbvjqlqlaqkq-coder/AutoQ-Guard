# AutoQ-Guard 개인정보·보안 설계

## 적용 원칙

- 공개 회원가입을 두지 않고 관리자가 업무상 필요한 계정만 발급한다.
- 이름·휴대전화·주소·주민등록번호는 수집하지 않는다. 표시명은 사번 또는 업무용 별칭을 권장한다.
- 비밀번호는 PBKDF2-SHA256(솔트, 310,000회) 일방향 해시로 저장한다.
- 접속주소는 원문 대신 HMAC 기반 `net_...` 가명 참조값으로 감사기록에 저장한다.
- 감사화면의 사용자 식별자는 `usr_...` 가명 참조값으로 표시한다.
- 로그인 5회 실패 시 15분 잠금, 세션 8시간, CSRF 토큰, 역할기반 권한검사를 적용한다.
- 감사기록 기본 보유기간은 90일이며 기간이 지난 기록은 자동 삭제한다.

## 수집 항목과 목적

| 항목 | 목적 | 저장 방식 |
|---|---|---|
| 계정ID·표시명/사번 | 본인확인·업무담당 구분 | 관리자 전용 원본, 감사화면 가명표시 |
| 비밀번호 | 인증 | 복원 불가능한 솔트 해시 |
| 역할·계정상태 | 접근통제 | 최소권한 RBAC |
| 로그인·변경 이력 | 침해사고 확인·책임추적 | 90일 보관 |
| 접속 식별자 | 비정상 접근 연계분석 | HMAC 가명값 |

## 의도적으로 제외한 기능

- 일반 사용자 자기 회원가입
- 주민등록번호, 생년월일, 개인 전화번호, 자택주소 수집
- 원본 IP의 감사화면 노출
- 복호화 가능한 비밀번호 저장

## 실제 기업 적용 전에 필요한 것

- 회사가 정한 처리 목적·법적 근거·보유기간에 맞춘 개인정보 처리방침 확정
- HTTPS, 기업 SSO/MFA, 비밀키 관리시스템(KMS/Secrets Manager), DB 암호화와 백업 암호화
- 개인정보처리자·수탁자 구분, 위탁계약, 파기절차, 정보주체 권리행사 절차
- 개인정보보호책임자와 법무·보안부서의 최종 검토

이 문서는 포트폴리오 PoC의 기술 설계이며 법률 자문 또는 법규 준수 인증서가 아니다.
