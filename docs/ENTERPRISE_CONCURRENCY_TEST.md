# 동시접속 부하시험

2,000개 LOT와 20,000대 VIN이 저장된 대량 시험 데이터베이스를 대상으로 20개 동시 작업자가 총 1,000회 LOT 검색을 요청합니다.

검색 결과의 LOT와 차량 10대가 정확한지, 요청 성공률, 데이터베이스 잠김 오류, 평균·95백분위·최대 응답시간과 초당 처리량을 측정합니다.

실행: `동시접속_부하시험.cmd`

결과: `results/enterprise_concurrency_test/concurrency_test_result.json`

이 시험은 한 대의 PC에서 조회 요청만 시험합니다. 실제 기업 서버, 사내망, 인증, 다중 사용자 데이터 수정 상황은 별도 시험 대상입니다.
