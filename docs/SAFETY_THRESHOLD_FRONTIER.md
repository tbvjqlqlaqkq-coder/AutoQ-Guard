# 안전부품 임계값 한계 분석

## 결과

SAFETY LOT의 점수 분포는 다음과 같았다.

| 위험점수 | 실제 결함 | 실제 정상 |
|---:|---:|---:|
| 0 | 0 | 216 |
| 40 | 5 | 14 |
| 95 | 0 | 5 |
| 100 | 10 | 0 |

40점에서 약한 결함 5개와 정상 14개가 겹친다. 40점 이하로 낮추면 안전 미탐은 0이지만 정상 14개에도 경보한다. 40점보다 높이면 이 오탐을 줄이는 대신 약한 안전결함 5개를 놓친다.

## 판단

임계값 미세조정만으로는 두 목표를 동시에 달성할 수 없다. 다음 단계에서는 시간에 따른 이상 증가, 검사 유형별 결과, 고장코드, 동일 협력사 반복 발생 등 추가 특징으로 같은 40점 LOT를 구분해야 한다. 실제 기업 적용 전에는 별도 기간 자료에서 다시 검증한다.

이 결과는 합성 기능시험이며 실제 기업 성능 또는 운영 임계값이 아니다.
