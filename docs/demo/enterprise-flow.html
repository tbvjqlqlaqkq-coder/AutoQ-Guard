기업 데이터 적용 전체 흐름

업로드부터 형식검사·위험도 계산·담당자 승인·감사기록까지 한 화면에서 시연합니다.

합성데이터 시연 환경 · 선택한 파일은 서버로 전송하지 않고 현재 브라우저 메모리에서만 읽습니다. 실제 기업 운영은 인증된 내부 서버와 승인 권한이 필요합니다.
STEP 01데이터 선택5개 표준 CSV 또는 합성 예시
STEP 02형식 검증필수 열·연결키·값 범위 확인
STEP 03위험도 계산고정 규칙으로 LOT 우선순위 산출
STEP 04담당자 검토결과 확인 후 승인·보류
STEP 05감사기록판단 근거와 시각을 JSON으로 저장

1. 데이터 반입

실제 파이프라인은 5개 CSV를 받습니다. 이 공개 시연에서는 파일명과 헤더만 검사합니다.

실행 기록

실제 실행과 시연을 혼동하지 않도록 각 단계의 상태를 남깁니다.

[대기] 데이터를 선택하거나 합성 예시를 불러오세요.

2–3. 검증 및 위험분석 결과

형식 검사를 통과해야 분석 버튼이 활성화됩니다.

영향 VIN-

의사결정 게이트: 분석 전 · 결과는 결함 확정이나 자동 리콜 명령이 아닙니다.

4–5. 담당자 승인과 감사기록

자동 계산 결과를 사람이 검토했다는 흔적을 남깁니다. 승인 없이는 운영 대응으로 전환되지 않습니다.

저장된 감사기록이 없습니다.
