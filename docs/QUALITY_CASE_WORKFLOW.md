# WATCH LOT 조사·승인 업무 흐름

## 상태 흐름

`WATCH → 조사 중 → 조치 제안 → 승인 또는 기각 → 종료`

정상 판단은 `조사 중 → 정상 해제 → 종료` 순서로만 가능하다. 중간 단계를 건너뛰거나 종료 사건을 다시 변경하면 차단한다.

## 권한

- QUALITY: 조사 시작, 조치 제안, 정상 해제, 종료
- ADMIN: 조사 시작, 조치 승인·기각, 종료
- VIEWER: 조회만 가능

조치 제안·승인·정상 해제에는 증거 문서 번호가 필수다. 모든 변경은 사용자·역할·시각·변경 전후 상태·사유·증거 참조를 기록한다. 감사 이벤트는 수정과 삭제를 DB 트리거로 차단하고 앞 기록의 해시를 연결해 변조 여부를 검사한다.

승인은 자동 리콜 명령이 아니다. 출고보류·추가검사·리콜 검토 요청을 승인하는 품질 업무 기록이며 실제 리콜 결정은 기업의 법무·안전·품질 절차를 따른다.

## 대시보드 API

- `GET /api/quality/cases`: 사건 목록
- `GET /api/quality/case?id=번호`: 사건과 전체 변경이력
- `POST /api/quality/cases`: WATCH 사건 생성
- `POST /api/quality/transition`: 상태 변경

변경 API는 로그인, `MANAGE_QUALITY_CASES` 권한과 CSRF 보안번호를 모두 검사한다. 공개 GitHub Pages 데모에는 변경 API가 없고 읽기 전용 설명만 제공한다.
