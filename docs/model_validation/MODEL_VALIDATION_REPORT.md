# AutoQ-Guard 시간순 예측모델 비교 보고서

> **2026-09-03 검증 상태 정정:** 아래 수치는 저장된 집계자료에 대한 과거 재현 결과다. 원본 최초 공개시점과 결과 관찰 종료일이 확인되지 않았고, 향후 12개월 정답이 학습·검증 경계를 넘을 수 있다. 따라서 시간순 분할만으로 미래정보 누출이 제거되었다거나 독립 예측 성능이 검증되었다고 해석하지 않는다. 기존 수치는 이력 보존을 위해 유지한다. [추가 검증 감사 보고서](PUBLIC_VALIDATION_AUDIT.md)를 먼저 참고한다.

## 결론

추적 완료 구간과 당시 관측 대상만 사용하는 고정 규칙 재평가 경로를 추가했다. [월말·관찰완료 평가 결과](MATURE_BACKTEST.md)를 참고한다. 아래 ML 결과는 기존 방식의 이력이며 이번 수정으로 자동 정정된 결과가 아니다.

현재 공개데이터에서는 로지스틱 회귀와 랜덤포레스트가 고정 경보규칙을 이기지 못했다. 따라서 AutoQ-Guard의 운영 후보는 기존 고정 규칙을 유지하고, 머신러닝 모델은 기업 데이터 확보 전까지 연구 후보로만 보류한다.

## 시험 설계

- 목표: 관측월 이후 12개월 안에 리콜이 발생하는지 예측
- 전체 관측치: 175,344건
- 학습: 2020-01~2023-12, 107,904건
- 검증: 2024-01~2024-12, 26,976건
- 최종 시험: 2025-01~2026-06, 40,464건
- 최종 시험 양성 비율: 3.77%
- 특징: 연식, 불만, 중대신호, 조사신호, 최근·직전 3개월 신호, 브랜드, 부품분류
- 모델: 고정 규칙, 로지스틱 회귀, 랜덤포레스트 300개 트리
- 임계값: 검증기간에서 고정 규칙 이상의 재현율을 요구한 뒤 FP=1·FN=10 비용 최소화
- 결과에 맞춘 무작위 분할을 사용하지 않고 과거로 학습해 미래를 평가했다.

## 최종 시험 결과

| 모델 | 경보 | 정밀도 | 재현율 | F1 | FP | FN | 비용단위 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 고정 경보규칙 | 1,645 | 8.02% | 8.66% | 8.33% | 1,513 | 1,392 | 15,433 |
| 로지스틱 회귀 | 6,767 | 1.20% | 5.31% | 1.95% | 6,686 | 1,443 | 21,116 |

비용단위는 실제 원화가 아니라 비교 목적의 `오탐 1 + 미탐 10` 가중치다. 실제 기업 비용이 제공되면 원화 기준으로 다시 계산해야 한다.

## 해석

- 고정 규칙은 세 모델 중 정밀도·재현율·F1과 비용단위가 모두 가장 나았다.
- 로지스틱 회귀는 경보를 크게 늘렸지만 실제 리콜 신호를 충분히 추가로 찾지 못했다.
- 랜덤포레스트는 과거 학습기간에는 패턴을 학습했지만 미래 시험기간에서 성능이 크게 떨어졌다.
- 시간에 따른 차량 구성·신고 양상·리콜 정책 변화와 낮은 양성 비율 때문에 모델의 미래 일반화가 어려웠을 가능성이 있다.
- 공개 불만 집계만으로는 기업 생산공정의 불량을 직접 예측하기에 정보가 부족하다는 한계가 다시 확인됐다.

## 기업 적용 결정

1. 현재 고정 규칙을 설명 가능한 기준선으로 유지한다.
2. ML 결과만으로 출고중단이나 리콜 결정을 하지 않는다.
3. 기업 LOT·공정검사·DTC·보증수리 데이터가 확보되면 같은 시간순 방식으로 재학습한다.
4. ML은 고정 규칙보다 재현율·정밀도·비용을 모두 개선할 때만 채택한다.
5. 안전부품은 모델 점수와 별개로 보수적인 안전 Gate를 유지한다.

## 프로젝트에서 사용할 표현

> 시간순 백테스트로 고정 규칙과 로지스틱 회귀·랜덤포레스트를 비교했지만, 공개데이터에서는 머신러닝 모델의 미래 성능이 더 낮았습니다. 결과를 과장하지 않고 고정 규칙을 유지했으며, 기업 내부 공정데이터가 확보되면 같은 검증절차로 재평가하도록 설계했습니다.

이 결과는 실패가 아니라 모델을 무조건 적용하지 않고 객관적으로 기각할 수 있는 검증 절차를 갖췄다는 근거다.
