# 경보 화면 수치 일관성 검증

2026-09-03. 공개 사후 검증 화면의 생성 파이프라인을 보완했다. 운영 경보와 로그인에는 변경이 없다.

## 수정

- 비교 그래프의 389/196/210 같은 상수 대신 동일 입력에 반복 경보 평가 함수를 실행한다.
- 표시 기간을 입력의 최소·최대 월로 계산한다.
- 빈 입력, 빈 그룹 키, 잘못된 월 시작일, 중복 그룹·월, 비정상 이진값은 생성을 중단한다.
- 생성 HTML의 경보 행 수·그룹 수를 입력과 대조한다.
- 입력 및 HTML SHA-256, 입력 행 수, 표시 행 수, 비교 결과를 alert_review_build.json에 보존한다.

- 고정 규칙 경보: 389 / 화면 경보: 389

## 재생성

저장소 루트에서 `python src/build_alert_review.py`를 실행한다. 먼저 results/purged_ml/test_predictions.csv가 필요하다. 원본 경보 파일은 Git의 results 제외 정책을 유지하며 이번 변경에서 공개하지 않았다.

해시와 행 수 검사는 생성 일관성을 확인한다. 데이터 진위·리콜 예방 효과·기업 안전성·브라우저 조작 정상 동작을 보증하지 않는다. Markdown 과거 보고서는 별도 실행 시점의 산출물이며 최신 화면의 수치는 해당 화면과 생성 기록을 기준으로 확인한다. 잘못된 새 입력은 기존 HTML을 덮어쓰지 않으므로, 실행 실패 시 남아 있는 이전 HTML을 최신 결과로 오인하지 않아야 한다.
