# 미래 정답 혼입 방지 ML 재시험 준비

상태: 데이터 분할 및 시간 경계 검증 완료. 모델 재학습은 미실행.

| 용도 | 관측기간 | 정답 관찰 종료 | 행 |
|---|---|---|---:|
| 학습 | 2020-01~2021-12 | 2022-12-31 | 13,177 |
| 임계값 검증 | 2023-01~2023-12 | 2024-12-31 | 16,533 |
| 평가 | 2025-01~2025-06 | 2026-06-30 | 11,289 |

2023년 초 학습 완료와 2025년 초 임계값 확정을 가정한다. 2022년·2024년의 관측행은 기간 사이에 비워 둔다. 전처리와 모델은 학습 자료에만 맞추고 이후 재학습하지 않는다. 시험 결과로 임계값이나 특징을 조정하지 않는다. 평가 대상은 첫 신호 이후의 제한된 감시 모집단이며 기존 보유기간 재분석이지 새로운 독립 시험은 아니다.

실행: 프로젝트 루트에서 `python src/prepare_purged_ml.py`.
결과: `results/purged_ml/protocol.json` 및 train/validation/test.csv.

전체 자동검사 40개 통과. 이번 실행 환경의 기본 Python에는 sklearn이 없고, 기존 별도 model_libs 사본은 접근 권한 오류가 발생했다. 모델은 아직 훈련하지 않았으며 예측 성능 결과도 생성하지 않았다. 다음 작업은 격리된 ML 실행환경을 준비하고 고정 규칙·로지스틱 회귀·랜덤포레스트를 같은 평가행에서 비교하는 것이다.

이 준비만으로 신고 수정 이력·조사 공개 날짜 검증까지 해결된 것은 아니다.
