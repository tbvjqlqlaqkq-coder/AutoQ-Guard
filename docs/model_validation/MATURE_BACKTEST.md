# 월말·관찰완료 평가 보완 (2026-09-03)

## 적용한 변경

- 경보는 해당 월 마지막 날 확정한다. 다음 12개의 완결된 월이 결과 관찰 창이다.
- 원본 생성 코드가 리콜을 2026-06-30까지 잘라 사용했으므로 2025-06 관측까지 평가한다.
- 미래 리콜 여부를 보지 않고 첫 신고·중대신호·조사 관측월부터 감시 대상에 포함한다.
- 관측된 대상 중 추적기간 부족은 PENDING_FOLLOWUP, 미관측 대상은 UNOBSERVED_COHORT로 분리한다.
- 판정 대기 행은 이미 양성이 기록돼 있어도 전체를 제외하며 평가 정답을 빈 값으로 출력한다.
- 기존 C3/P3/S3/I3 경보규칙은 변경하지 않았다.

## 재실행 결과

전체 기존 시험구간 2025-01~2026-06의 40,464행:

| 상태 | 행 |
|---|---:|
| 관측된 대상 + 추적 완료 | 11,289 |
| 관측된 대상 + 판정 대기 | 24,794 |
| 당시 신호가 없는 대상 | 4,381 |

기간만 보면 26,976행이 추적 미완료다. 그중 2,182행은 미관측 대상으로 먼저 분류돼 있으므로 위 표의 판정 대기 수와 다르다. 이 단위는 차량 대수나 고유 리콜 건수가 아니다.

관측된 대상의 추적완료 구간(2025-01~2025-06): TP 42, FP 347, FN 302, TN 10,598. 정밀도 10.80%, 재현율 12.21%, 거짓 양성률 FP/(FP+TN) 3.17%.

이 지표는 좁아진 감시 모집단에 대한 값이다. 기존 정밀도 8.02%·재현율 8.66%보다 향상됐다고 해석하지 않는다. 기간만 제한하고 기존 모집단을 유지한 이전 시나리오의 재현율은 5.84%였다. 신호가 없던 미탐지 대상도 이번 모집단에서 빠지므로 재현율 상승을 모델 개선으로 주장하면 안 된다. 잠재 결함이 있으나 신고·조사가 전혀 없는 차량은 이 방식으로 평가할 수 없다.

## 해결 범위와 남은 한계

관찰기간 미완료 행을 음성으로 평가하는 문제, 월초 예측으로 오해할 수 있는 표기, 미래 리콜로만 과거 감시 대상을 만드는 문제를 이 별도 평가 경로에서 보완했다. 기존 보고서는 재현 이력으로 보존했다.

첫 신호 기준은 실제 당시 차량 판매·등록 모집단의 대체 지표다. 역사적 전체 차량 모집단을 복원한 것은 아니다. 신호 내용의 최초 공개 시점·수정 이력과 조사 공개 날짜는 여전히 입증하지 못했다. 기존 머신러닝 시험은 별도 과거 재현 경로이며 이번에 재학습하지 않았다. 학습 정답의 성숙기간을 반영한 ML 재시험도 아직 남아 있다.

## 실행

프로젝트 루트에서 `python src/mature_public_backtest.py` 실행.

- `results/mature_public_backtest/summary.json`: 요약 및 원본 해시
- `results/mature_public_backtest/evaluation_rows.csv`: 월말 시점, 결과 관찰 종료일, 분리 상태, 평가 정답
- `python -m unittest discover -s tests`: 회귀시험

신규 독립 시험·실제 리콜 예방률·기업 ROI를 입증하는 결과가 아니다.
