# 공개 경보 화면 수동 브라우저 검증

검증일: 2026-09-03. 대상 커밋: fd7b996. 대상: https://tbvjqlqlaqkq-coder.github.io/AutoQ-Guard/demo/alert-review.html

실제 Codex 내장 브라우저에서 공개 HTTPS 화면을 조작했다. 다음은 이전 작업에서 관측한 결과이며 CI 브라우저 자동시험으로 주장하지 않는다.

| 검사 | 관측 결과 |
|---|---|
| 최신 배포 구분 | 2025-01 ~ 2025-06 입력 평가 구간, 자동 계산 그래프 표시 |
| 공백·소문자 포함 `  hyundai  ` 검색 | 95개 그룹 표시 |
| 검색 결과 펼치기 | 표 95개 노출 |
| 접기 | 표 0개 노출 |
| 존재하지 않는 검색어 | 검색 결과 없음 안내 |
| 키보드 전체 선택·Backspace로 검색어 삭제 | 186개 그룹 복원 |
| 전체 펼치기 | 표 186개, 헤더 포함 575행 = 원본 경보 389행 + 헤더 186행 |
| ELANTRA 2015 ENGINE_FUEL 개별 펼치기 | 표 1개, 헤더 포함 4행 |
| 검사 중 수집된 오류 로그 | 없음 |

빈 문자열을 입력하는 자동화 fill 호출은 검색어를 지우지 못했다. 실제 키보드 삭제로 복원 동작을 확인했으며 해당 fill 호출 자체를 통과로 기록하지 않았다.

## 자동 검사 범위

GitHub CI의 기존 Python 3.10/3.12 테스트에 공개 HTML과 생성 기록의 일치 검사를 추가했다. 원본 비공개 파일이나 ML 라이브러리 없이 수행한다. 현재 로컬 통과가 원격 CI 실행 성공을 의미하지 않는다.

HTML 해시(줄바꿈 정규화), 경보 행 수, 그룹 수, 원본 식별 해시 및 비교 결과의 범위를 검사한다. 불일치 시 실패하며, `python src/build_alert_review.py`로 입력을 검증한 뒤 화면과 생성 기록을 함께 갱신해야 한다.

## 한계

모바일·다른 브라우저·실제 기업 로그인·부하·침투 테스트는 이번 검증 범위가 아니다. 파일과 생성 기록을 동시에 조작하면 해시 검사만으로 진위를 보장할 수 없다. CI 실패가 현재 설정에서 GitHub Pages 배포를 자동 차단하는 것은 아니며, 별도 배포 의존성/보호 설정이 필요하다. 실제 리콜 예방 및 ROI는 검증되지 않았다.
