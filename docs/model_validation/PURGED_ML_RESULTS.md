# 정답 성숙기간을 적용한 ML 비교 결과 — 2026-09-03

## 결론

동일한 시험 11,289행에서 고정 규칙이 정밀도·F1·FP+10FN 비교비용에서 가장 나았다. 로지스틱 회귀는 재현율이 높지만 경보와 오탐이 크게 늘었다. 실제 비용 정책이 없으므로 모든 조건에서 고정 규칙이 최선이라는 뜻은 아니다. 운영 모델은 변경하지 않았다.

## 고정한 설계

- 학습 관측: 2020~2021년 13,177행, 정답 관찰은 2022년 말까지. 가상 학습 시점 2023-01-01.
- 임계값 검증 관측: 2023년 16,533행, 정답은 2024년 말까지. 가상 임계값 고정 시점 2025-01-01.
- 시험 관측: 2025년 1~6월 11,289행, 정답은 2026-06-30까지. 양성 344행.
- 해당 월말에 예측하며 첫 신호부터 포함하는 제한된 감시 모집단이다.
- 전처리·모델은 학습 자료에만 적합하며 검증 후 재학습하지 않는다.
- 특징은 YEAR, COMPLAINTS, SERIOUS, INVESTIGATIONS, C3, P3, S3, I3, BRAND, CAT. 정답·미래 리콜·상태 열은 특징에서 제외한다.
- 검증자료에서 고정 규칙 이상의 재현율을 만족하는 임계값 중 FP+10FN 최소값 선택. 그리드 0.05~0.95, 간격 0.01. 만족 후보가 없으면 기각한다.
- 로지스틱 회귀 max_iter=2000, class_weight=balanced; 랜덤포레스트 300개 트리, min_samples_leaf=5, class_weight=balanced_subsample. 난수 20260805 고정.

## 동일 시험자료 비교

| 모델 | 임계값 | 경보 | TP | FP | FN | 정밀도 | 재현율 | F1 | 비교비용 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 고정 규칙 | 기존 규칙 | 389 | 42 | 347 | 302 | 10.80% | 12.21% | 11.46% | 3,367 |
| 로지스틱 회귀 | 0.65 | 2,612 | 129 | 2,483 | 215 | 4.94% | 37.50% | 8.73% | 4,633 |
| 랜덤포레스트 | 0.67 | 1,277 | 24 | 1,253 | 320 | 1.88% | 6.98% | 2.96% | 4,453 |

비교비용은 원화가 아니다. 정밀도와 재현율은 월별 관측행 단위이며 리콜 캠페인·예방 차량 단위가 아니다. 기존 모델 보고서와 학습기간·모집단이 달라 전후 성능 향상을 주장하지 않는다. 검증기간 비용도 고정 규칙 8,108, 로지스틱 8,587, 랜덤포레스트 8,653으로 ML 우위가 확인되지 않았다.

## 재현과 테스트

Python 3.12.13, scikit-learn 1.7.1. 기존 런타임을 변경하지 않고 별도 패키지 디렉터리에서 실행했다. 모델 패키지 환경에서 전체 42개 자동시험 통과.

별도 가상환경에서 `pip install -r requirements-ml-validated.txt` 후 프로젝트 루트에서 `python src/run_purged_ml.py` 실행.

- `results/purged_ml/model_comparison.json`: 버전·원본 해시·검증/시험 결과
- `results/purged_ml/test_predictions.csv`: 시험행별 모델 예측
- `tests/test_purged_threshold.py`: 임계값 선택과 후보 없음 처리 시험

## 남아 있는 한계

보유기간은 이미 살펴본 과거 자료이므로 신규 독립 시험이 아니다. 정답의 시간 경계를 보완했지만, 원본 내용의 과거 공개·수정 이력과 조사 I3의 공개 가능일은 검증되지 않았다. 관측되지 않은 차량은 제외된 제한 모집단이며 실제 기업 예방률·원화 ROI·운영 안전을 증명하지 않는다. 공개 성능 비교를 근거로 자동 출고중단·리콜 결정을 하지 않는다.
