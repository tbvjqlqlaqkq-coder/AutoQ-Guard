# 2단계: 기업 데이터 변환·적용 준비

## 무엇이 달라졌나

기업 원본의 한글 파일명과 열 이름을 프로젝트 표준형식으로 변환한 뒤 1단계 오류검사를 자동 실행합니다.

예시:

```text
기업 원본 `부품LOT번호` → 표준 `lot_id`
기업 원본 `차대번호` → 표준 `vin`
기업 원본 `재검률` 값 `8%` → 표준 비율 `0.08`
기업 원본 `2026.01.10` → 표준 날짜 `2026-01-10`
```

## 기업자료를 받았을 때 절차

1. 받은 원본 CSV를 별도 폴더에 복사합니다. 원본은 수정하지 않습니다.
2. `enterprise_data/demo_company_mapping.json`을 복사해 기업명으로 저장합니다.
3. `source_file`에 실제 파일명을 적습니다.
4. `columns` 오른쪽에 기업 원본의 실제 열 이름을 적습니다.
5. 변환·검사 명령을 실행합니다.

```text
python src/enterprise_import.py 기업원본폴더 기업매핑.json --work-dir results/기업명_import
```

## 출력 구조

```text
results/기업명_import/
├─ standardized/       표준형식으로 변환된 5개 CSV
├─ validation/         1단계 오류검사 결과
└─ import_reports/     변환과정·원본 해시·오류 보고서
```

## 안전장치

- 매핑되지 않은 필수 열이 있으면 중단
- 원본에 지정한 열이 없으면 중단
- 숫자·날짜·퍼센트 변환 실패 시 중단
- 상위폴더 등 허용되지 않은 경로 접근 차단
- 원본파일 SHA-256 기록
- 원본 행 수와 변환 행 수 기록
- 변환 완료 후 1단계 검증이 통과돼야 `READY`

## 현재 가능한 것과 남은 것

현재는 기업 CSV 형식을 한 번 매핑하면 동일한 형식의 다음 데이터부터 자동 변환·검사할 수 있습니다. Excel, 데이터베이스 직접연결, 대용량 분할처리, 기업별 코드사전은 다음 확장 대상입니다. 위험 LOT 계산과 화면 연결은 검증된 표준데이터를 이용하는 다음 단계입니다.
