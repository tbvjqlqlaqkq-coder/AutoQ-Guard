# AutoQ-Guard | 자동차 부품 품질위험–리콜 조기경보 PoC

공개 자동차 품질·리콜 데이터와 합성 생산 LOT 데이터를 결합하여 잠재적 부품 결함의 리콜 위험을 조기에 탐지하고, 예상 회피손실과 ROI를 계산하는 개인 프로젝트입니다.

이 저장본은 **기업 운영 완제품이 아니라 공개데이터로 가능성을 검증한 재현 가능한 PoC**입니다.

## 핵심 질문

1. 소비자 불만·조사 신호가 실제 리콜보다 먼저 나타나는가?
2. 공정·부품 LOT·차량·현장품질을 연결하면 위험 범위를 더 일찍 좁힐 수 있는가?
3. 조기대응 비용과 예상 회피손실을 같은 기준으로 비교할 수 있는가?

## 주요 결과

| 근거 등급 | 데이터 | 결과 | 해석 |
|---|---|---|---|
| A 공개 관측 | NHTSA 기반 현대·기아 공개자료 | 12개월 탐지율 20.6%, 정밀도 8.1%, 중앙 선행기간 4.5개월 | 리콜 전 선행 신호 가능성 확인 |
| B 합성 기능시험 | 120개 합성 LOT | 고정 규칙 블라인드 Gate 통과 | LOT 단위 연결·경보 흐름 작동 확인 |
| C 가정 시뮬레이션 | 비용·차량수·성공률 분포 | 기준 ROI 34.0%, ROI 10% 이상 확률 93.6% | 가정 조건에서 경제성 범위 산출 |
| D 기업 실증 | 아직 없음 | 미확정 | 기업 내부 데이터로 실제 성능·ROI 측정 필요 |

### 중요한 해석

- `20.6%·8.1%·4.5개월`은 실제 공개데이터 백테스트 결과입니다.
- 합성 LOT 결과는 기능시험이며 실제 생산라인 성능이 아닙니다.
- `ROI 34.0%·93.6%`는 명시된 가정의 시뮬레이션 결과이며 기업 ROI 보장값이 아닙니다.
- 기업 데이터가 제공되면 실제 탐지율, 오탐 비용, 영향 차량 수, 직접 회피손실과 ROI를 측정할 수 있습니다.

## 빠른 실행

Python 3.10 이상에서 합성 기업 데이터를 처리한 뒤 대시보드를 실행합니다.

```bash
python src/enterprise_pipeline.py enterprise_data/demo_company_raw enterprise_data/demo_company_mapping.json
python src/enterprise_dashboard.py
```

브라우저에서 `http://127.0.0.1:8765`에 접속합니다. 최초 관리자 정보는 로컬 `results/security/초기_관리자_계정.txt`에 한 번만 생성되며 Git에 포함되지 않습니다.

Docker에서는 `.env.example`을 `.env`로 복사하고 비밀번호와 HMAC 키를 각각 강한 임의값으로 바꾼 뒤 `docker compose up --build`를 실행합니다.

실행 후 생성되는 파일:

- `results/project_results.json`: 전체 계산 결과
- `results/result_classification.csv`: 공개·합성·가정·기업 실증 등급표
- `results/reproduction_report.txt`: 사람이 읽기 쉬운 재현성 보고서

## 공개데이터 경보 규칙

다음 중 하나를 만족하면 경보로 정의했습니다.

```text
C3 ≥ 5 이고 (P3 = 0 또는 C3 ≥ 2 × P3)
또는 S3 ≥ 2
또는 I3 ≥ 1
```

- `C3`: 최근 3개월 불만 건수
- `P3`: 직전 3개월 불만 건수
- `S3`: 최근 3개월 중대 신호
- `I3`: 최근 3개월 조사 신호

경보 규칙은 백테스트 전에 고정해 결과에 맞춘 사후 조정을 줄였습니다.

## 경제성 계산

```text
예방 차량 = 고위험 차량 × 조기대응 성공률
회피손실 = 예방 차량 × 출고 후 차량당 비용
총비용 = 조기조치비 + 오탐비 + 준비재고비 + 고정비 + 성과금
순편익 = 회피손실 - 총비용
ROI = 순편익 / 총비용
```

기준안:

- 고정비 2,000만원
- 성과금: 검증된 직접 회피손실의 10%
- 성과금 상한 1,500만원
- 기업 실증 Gate: 순편익 `> 0`, ROI `≥ 10%`

## 기업 데이터 적용 시 필요한 데이터

- 부품 LOT·공급사·입고·생산 시각
- 공정 검사값·재검률·설비·작업조건
- LOT–차량 장착 이력과 가명 차량키
- DTC·보증수리·고객불만·수리비
- 실제 조기조치비·물류비·부품비·고객보상비

기업 데이터가 들어온다고 성능이 자동으로 좋아지는 것은 아닙니다. 다만 해당 기업 기준의 실제 성능과 ROI를 **더 정확하게 측정하고, 미달 시 중단 판단**을 할 수 있습니다.

## 기업형 데이터베이스 v2 설계

`docs/database_v2`에는 기업 파일럿을 위한 PostgreSQL 목표 스키마, ERD, 데이터 사전과 무결성 검사 SQL이 있습니다. SQLite는 시연과 회귀시험용입니다. PostgreSQL 실구동·대량조회·트랜잭션 롤백은 검증했지만 실제 기업의 SSO·KMS·백업복구·보안관제 연결과 운영 승인은 남아 있습니다.
